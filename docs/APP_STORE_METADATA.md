## Description (4000 chars max)

```
Principal AI transforms GitHub activity into a visual experience. Watch commits come to life through File City — a two dimensional visualization that turns your repository's structure.

WHAT YOU'LL SEE

• Live Activity Feed — Recent commits from featured repositories, grouped by hour
• Change Visualizations — Changed Files Highlighted
• Commit Details — Author, message, timestamps, and code stats at a glance
• Commit Timeline — Swipe through commits and watch the city change with each one

DESIGNED FOR DEVELOPERS

Built for those who appreciate code as craft. Whether you're tracking your favorite open source projects or just want a beautiful way to see what's happening in the developer world, Principal AI brings GitHub activity to your pocket.

FEATURES

• Pull-to-refresh to see the latest commits
• Swipe vertically between repositories
• Swipe horizontally between commits
• Tap the commit timeline to jump between changes

No account required to browse the activity feed.

From Noetic Labs — building tools for developers who see code differently.
```
