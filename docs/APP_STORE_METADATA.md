## Description (4000 chars max)

```
Principal ADE transforms GitHub activity into a visual experience. Watch commits come to life through File City — an isometric visualization that turns your repository's structure into a living cityscape.

WHAT YOU'LL SEE

• Live Activity Feed — Recent commits from featured repositories, grouped by hour
• File City Visualizations — Each repository rendered as an isometric city where files become buildings
• Commit Details — Author, message, timestamps, and code stats at a glance
• Commit Timeline — Swipe through commits and watch the city change with each one

DESIGNED FOR DEVELOPERS

Built for those who appreciate code as craft. Whether you're tracking your favorite open source projects or just want a beautiful way to see what's happening in the developer world, Principal ADE brings GitHub activity to your pocket.

FEATURES

• Pull-to-refresh to see the latest commits
• Swipe vertically between repositories
• Swipe horizontally between commits
• Tap the commit timeline to jump between changes
• Auto-refreshes every 5 minutes

No account required to browse the activity feed. Sign in with GitHub to access your own repositories.

From Noetic Labs — building tools for developers who see code differently.
```
